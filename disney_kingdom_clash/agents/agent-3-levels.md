# Agent 3 – Levels and Waves

Level definitions live in `js/data/levelData.js`. Each level entry specifies:

- `id`, `name` and `description` – Strings used in the planning screen.
- `background`, `groundTexture` and `pathTexture` – Image paths for the scene.
- `xpReward` and `trophyReward` – Rewards for completing the level.
- `trophyRequirement` – Minimum trophies needed to unlock the level.

Enemy waves are stored in `js/data/waveData.js`. Each wave references a `glitch` id, spawn count and timing. Glitch attributes (hit points, speed, model images) are defined in `js/data/glitchData.js`.

The grid and path layout is generated by `managers/gridManager.js` using level data when the scene is initialized.
