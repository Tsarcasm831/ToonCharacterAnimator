# Agents Directory

This folder contains detailed guides for the major systems in Disney Kingdom Clash. Each document is written from the perspective of an expert assistant ("agent") covering a single subsystem. Use these files to get oriented quickly.

- [agent-1-overview.md](agent-1-overview.md) – high-level explanation of gameplay flow and major modules.
- [agent-2-hero-data.md](agent-2-hero-data.md) – structure of hero definitions and how to add new heroes.
- [agent-3-levels.md](agent-3-levels.md) – description of level data and wave configurations.
- [agent-4-managers.md](agent-4-managers.md) – responsibilities of runtime managers (Grid, Unit, Enemy, Hero, Scene).
- [agent-5-ui.md](agent-5-ui.md) – how UI screens are defined and injected at runtime.
- [agent-6-assets.md](agent-6-assets.md) – asset pipeline and preloading mechanics.
